The purpose of this matrix is that **no syllabus topic can be forgotten**: every topic in the source appears as one row in a per-part detail file, with the document that covers it (or the planned location if it is not written yet) and an honest status.

## Status definitions

| Status | Meaning |
| --- | --- |
| Not started | No document covers this topic yet. The planned chapter directory is shown. |
| In progress | A document is being written but is incomplete. |
| Drafted | A full lesson exists and has passed the automated checks (links, front matter, runnable code, Mermaid). It has **not** had an independent technical review. |
| Reviewed | A person other than the author has checked technical accuracy against the cited sources. |
| Complete | Reviewed, and meets the completion standard below. |

### Completion standard

A topic is **not** complete because its file exists. It is complete when a beginner can understand it, an intermediate learner can implement it, and an advanced engineer can understand its internal workings and trade-offs. The lesson template in [CONTRIBUTING.md](../CONTRIBUTING.md) lists the sections that make this checkable.
