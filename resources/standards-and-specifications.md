# Standards and Specifications

Primary sources are preferred over summaries. Bodies and documents are named so they can be located; only stable, well-known addresses are linked.

| Standard or specification | Body | Used for | Where |
|---|---|---|---|
| IEEE Std 754-2019, *IEEE Standard for Floating-Point Arithmetic* | IEEE | Binary and decimal floating-point formats, rounding, exceptions | [IEEE Standards](https://standards.ieee.org/) |
| The Unicode Standard | Unicode Consortium | Code points, character properties, encoding forms | [unicode.org](https://www.unicode.org/) |
| RFC 3629, *UTF-8, a transformation format of ISO 10646* | IETF | The UTF-8 encoding | [RFC Editor](https://www.rfc-editor.org/rfc/rfc3629) |
| RFC 2781, *UTF-16, an encoding of ISO 10646* | IETF | The UTF-16 encoding and byte-order mark | [RFC Editor](https://www.rfc-editor.org/rfc/rfc2781) |
| RFC 20, *ASCII format for Network Interchange* | IETF | The ASCII character set | [RFC Editor](https://www.rfc-editor.org/rfc/rfc20) |
| RFC 4648, *The Base16, Base32, and Base64 Data Encodings* | IETF | Text encodings of binary data | [RFC Editor](https://www.rfc-editor.org/rfc/rfc4648) |
| RFC 8259, *The JavaScript Object Notation (JSON) Data Interchange Format* | IETF | JSON syntax | [RFC Editor](https://www.rfc-editor.org/rfc/rfc8259) |
| RFC 9110, *HTTP Semantics* | IETF | The request/response model of HTTP | [RFC Editor](https://www.rfc-editor.org/rfc/rfc9110) |
