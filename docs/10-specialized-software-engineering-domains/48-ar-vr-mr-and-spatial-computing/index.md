## Introduction

Augmented, virtual and mixed reality: tracking, rendering for head-mounted displays, interaction design and spatial computing platforms.

## Learning outcomes

After working through this subject you should be able to:

- Explain tracking, pose estimation and latency requirements
- Design for comfort and spatial interaction
- Build a basic immersive application
