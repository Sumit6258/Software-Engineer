## Introduction

Parallel programming, vectorisation, GPUs, cluster computing and the performance models used in scientific and large-scale computing.

## Learning outcomes

After working through this subject you should be able to:

- Parallelise a computation and measure its speed-up
- Explain the roofline model and memory-bound limits
- Use message passing and GPU programming models
