## Introduction

Connected devices end to end: device firmware, protocols, gateways, cloud platforms, security and operations at scale.

## Learning outcomes

After working through this subject you should be able to:

- Design an IoT architecture from device to cloud
- Choose appropriate protocols for constrained devices
- Plan secure provisioning and updates
