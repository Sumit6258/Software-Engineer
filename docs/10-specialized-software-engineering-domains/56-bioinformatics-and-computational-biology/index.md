## Introduction

Computational methods for biological data: sequences, alignment, genomics pipelines and machine learning in biology.

## Learning outcomes

After working through this subject you should be able to:

- Implement sequence alignment algorithms
- Build a reproducible analysis pipeline
- Interpret biological results with appropriate statistical care
