## Introduction

Moving computation towards data sources: edge architectures, constraints, orchestration and the relationship to cloud and IoT.

## Learning outcomes

After working through this subject you should be able to:

- Decide what to run at the edge and what in the cloud
- Handle intermittent connectivity
- Operate fleets of edge nodes
