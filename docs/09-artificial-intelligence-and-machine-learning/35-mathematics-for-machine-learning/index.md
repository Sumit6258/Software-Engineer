## Introduction

The linear algebra, calculus, probability, statistics and optimisation that machine-learning algorithms are built from.

## Learning outcomes

After working through this subject you should be able to:

- Derive gradients for simple models
- Use probability to reason about uncertainty and likelihood
- Explain how optimisation algorithms converge
