## Introduction

Native and cross-platform desktop applications, their UI toolkits, packaging, distribution and update mechanisms.

## Learning outcomes

After working through this subject you should be able to:

- Choose a desktop framework for a given product
- Package and distribute an application
- Manage state and threading in a GUI
