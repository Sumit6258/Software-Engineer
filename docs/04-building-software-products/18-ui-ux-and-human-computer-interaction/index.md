## Introduction

How people interact with software: user research, interaction design, usability, accessibility, visual design and evaluation methods.

## Learning outcomes

After working through this subject you should be able to:

- Run a basic usability test and act on the findings
- Apply accessibility guidelines
- Prototype and critique interface designs
