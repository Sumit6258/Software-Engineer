# Part XV — The Practical Learning Order

> [Home](../../README.md) › Part XV

A realistic order for learning, and a clear distinction between generalist foundations and specialist depth.

> One mistake would be attempting to learn all 64 areas simultaneously. The map is comprehensive, but the depth required in each area depends on your specialization.

## Twelve stages

```mermaid
flowchart LR
    T1["Stage 1: Beginner"] --> T2["Stage 2: Beginner → Intermediate"] --> T3["Stage 3: Intermediate"] --> T4["Stage 4: Intermediate"] --> T5["Stage 5: Intermediate"] --> T6["Stage 6: Intermediate → Advanced"] --> T7["Stage 7: Advanced"] --> T8["Stage 8: Advanced"] --> T9["Stage 9: Specialist"] --> T10["Stage 10: Advanced specialist"] --> T11["Stage 11: Specialist"] --> T12["Stage 12: Research/specialist"]
```
