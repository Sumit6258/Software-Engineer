## Introduction

Git from first commit to advanced history manipulation, hosting platforms, branching strategies, pull requests and collaborative workflows.

## Learning outcomes

After working through this subject you should be able to:

- Use branches, merges and rebases confidently
- Recover from mistakes using the reflog and reset
- Run a pull-request based team workflow
