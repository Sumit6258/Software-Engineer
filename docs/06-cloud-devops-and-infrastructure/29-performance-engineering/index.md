## Introduction

Measuring and improving performance: profiling, benchmarking, load and stress testing, tuning across the stack and capacity.

## Learning outcomes

After working through this subject you should be able to:

- Profile before optimising
- Design a load test and read its results
- Identify CPU, memory, I/O and lock bottlenecks
