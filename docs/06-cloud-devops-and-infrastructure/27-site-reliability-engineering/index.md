## Introduction

Reliability as an engineering discipline: service-level objectives, error budgets, incident response, capacity and toil reduction.

## Learning outcomes

After working through this subject you should be able to:

- Define SLIs and SLOs for a service
- Run an incident and write a blameless post-mortem
- Reduce toil through automation
