# Glossary

Short definitions of the terms introduced so far, each linking to the lesson that explains it properly. The glossary grows with the library; terms from lessons that have not been written yet are not defined here.

## A

- **Absolute value**: The distance of a number from zero, written |x|. The inequality |x − a| < r says that x is within r of a. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **Absorption**: In floating-point addition, the loss of a small operand when it is added to a much larger one, because the sum rounds back to the larger value. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Address (memory address)**: The number that identifies one byte-sized cell of memory. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).
- **Addressing mode**: The rule an instruction uses to say where its memory operand is: an address written in the instruction, an address held in a register, a register plus an offset, or an address relative to the PC. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Aliasing (sampling)**: The effect of sampling a signal too slowly, so that high frequencies appear as lower ones. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).
- **Alignment**: Placing a value at an address that is a multiple of its size, which many processors require or prefer. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).
- **ALU (arithmetic logic unit)**: The part of a processor that performs integer arithmetic and bitwise operations. See [Binary Arithmetic](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/03-binary-arithmetic.md).
- **Amdahl's law**: The speed-up from parallelism is limited by the part of the work that must stay serial: S = 1 / ((1 - p) + p / n). See [The CPU and the GPU](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/01-cpu-and-gpu.md).
- **Arithmetic sequence**: A sequence in which each term is the previous one plus a constant step. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Aspect ratio**: The ratio of an image's or screen's width to its height, such as 16:9. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).
- **Assembler**: A program that translates assembly language into machine code, replacing labels with addresses. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Assembly language**: A readable text form of machine code in which each instruction is a mnemonic followed by its operands. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).

## B

- **Backward and forward compatibility**: Backward: new code can read old data. Forward: old code can read new data, typically by ignoring unknown fields. See [Data Serialization](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/07-data-serialization.md).
- **Bandwidth**: The amount of data a link can carry per unit of time. Not the same as latency. See [Client-Server and Remote Computing](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/03-client-server-and-remote-computing.md).
- **Base (radix)**: The number of distinct digit symbols in a positional system, and the factor between adjacent place values. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Bias (exponent bias)**: A constant added to a floating-point exponent so that it can be stored as an unsigned field: 127 for binary32 and 1023 for binary64. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Big-endian**: Byte order that stores the most significant byte at the lowest address. See [Integers, Floating-Point Numbers and Endianness in Memory](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/05-integers-floats-and-endianness-in-memory.md).
- **Bijection**: A function that is both one-to-one and onto, pairing the elements of two sets perfectly. Only a bijection has an inverse. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Binary search**: Finding an item in a sorted list by repeatedly halving the part still to be searched; it needs about log₂ n comparisons. See [Exponents and Logarithms](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/02-exponents-and-logarithms.md).
- **Binary-coded decimal (BCD)**: A code that stores each decimal digit in its own 4 bits. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Binomial coefficient**: The number C(n, k) of k-element subsets of an n-element set, and an entry of Pascal's triangle. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Birthday bound**: With N equally likely values, a repeat becomes likely after about 1.18√N items. This is why hash outputs must be long. See [The Pigeonhole Principle and Inclusion-Exclusion](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/04-pigeonhole-and-inclusion-exclusion.md).
- **Bit**: A binary digit, 0 or 1; the smallest unit of information in a digital computer. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Bit depth**: The number of bits used to store each sample or colour channel. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).
- **Bitwise operation**: An operation applied independently to every bit position of its operands: AND, OR, XOR, NOT and shifts. See [Binary Arithmetic](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/03-binary-arithmetic.md).
- **Boolean algebra**: The algebra of two-valued quantities, with AND, OR and NOT and laws for transforming expressions. See [Boolean Algebra and De Morgan's Laws](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/02-boolean-algebra-and-de-morgans-laws.md).
- **Byte**: Eight bits in practice; the smallest addressable unit of memory. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).
- **Byte order mark (BOM)**: The character U+FEFF placed at the start of text so a reader can tell the byte order or encoding. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).

## C

- **Cache**: A small, fast memory holding copies of recently used data from a larger, slower memory. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Cache hit and cache miss**: A hit finds the requested data in the cache; a miss must fetch it from the next level. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Cache line**: The unit of data a cache moves at a time, typically 64 bytes. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Cardinality**: The number of elements of a finite set, written |A|. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Carry**: The value passed to the next column when a column's sum is too large for one digit. See [Binary Arithmetic](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/03-binary-arithmetic.md).
- **Carry-lookahead adder**: An adder that computes all carries in parallel from generate and propagate signals instead of waiting for them to ripple. See [Binary Arithmetic](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/03-binary-arithmetic.md).
- **Cartesian product**: The set A × B of all ordered pairs (a, b) with a in A and b in B. It has |A| × |B| elements. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Catastrophic cancellation**: The loss of most significant digits when two nearly equal floating-point numbers are subtracted. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Character encoding**: A rule for writing the numbers of a character set as bytes. See [Character Encoding and ASCII](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/03-character-encoding-and-ascii.md).
- **Checksum**: A short value computed from data, such as a sum, used to detect accidental changes. See [Error Detection and Correction](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/02-error-detection-and-correction.md).
- **Chroma subsampling**: Storing colour at lower resolution than brightness, because the eye is less sensitive to colour detail. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).
- **Client**: A program (or the machine running it) that initiates a request for a service. See [Client-Server and Remote Computing](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/03-client-server-and-remote-computing.md).
- **Clock rate**: The frequency, in hertz, of the signal that paces a processor. See [The CPU and the GPU](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/01-cpu-and-gpu.md).
- **Closed form**: A formula for the nth term of a sequence that needs no earlier terms. See [Mathematical Induction and Recurrence Relations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/03-induction-and-recurrence-relations.md).
- **Code point**: The number Unicode assigns to a character, written U+ followed by hexadecimal digits. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).
- **Code unit**: The fixed-size piece an encoding is built from: one byte in UTF-8, 16 bits in UTF-16. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).
- **Codec and container**: A codec compresses and decompresses a stream; a container packages compressed streams into a file. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).
- **Combination**: A selection of objects in which order does not matter. There are n!/(k!(n − k)!) selections of k objects from n. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Combinational logic**: Logic whose output depends only on its present inputs, with no memory. See [Logic Gates and Truth Tables](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/01-logic-gates-and-truth-tables.md).
- **Combinatorics**: The mathematics of counting arrangements, selections and structures. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Composition (of functions)**: Applying one function to the result of another: (g ∘ f)(x) = g(f(x)). The order matters. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **Compound growth**: Growth in which an amount is multiplied by the same factor, 1 + r, every period, so it reaches P(1 + r)ⁿ after n periods. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).
- **Computer**: A programmable machine that follows stored instructions to turn input into output, using memory to hold both instructions and data. See [What Is a Computer?](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/01-what-is-a-computer.md).
- **Context switch**: Saving the registers of the running program and loading those of another, so that one processor can run many programs in turn. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Core**: A complete processing unit of a CPU; a multi-core CPU has several on one chip. See [The CPU and the GPU](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/01-cpu-and-gpu.md).
- **CPI (cycles per instruction)**: The average number of clock cycles a processor spends per instruction. See [The CPU and the GPU](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/01-cpu-and-gpu.md).
- **CRC (cyclic redundancy check)**: An error-detecting code from polynomial division over GF(2), strong against bursts of errors. See [Error Detection and Correction](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/02-error-detection-and-correction.md).

## D

- **Data model (ILP32, LP64, LLP64)**: The set of sizes a C platform gives to int, long and pointers. See [Integers, Floating-Point Numbers and Endianness in Memory](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/05-integers-floats-and-endianness-in-memory.md).
- **De Morgan's laws**: The complement of an AND is the OR of the complements, and the complement of an OR is the AND of the complements. See [Boolean Algebra and De Morgan's Laws](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/02-boolean-algebra-and-de-morgans-laws.md).
- **Derangement**: An ordering of items in which no item is in its original position. For large n about 1/e of all orderings are derangements. See [The Pigeonhole Principle and Inclusion-Exclusion](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/04-pigeonhole-and-inclusion-exclusion.md).
- **Deserialization**: Rebuilding in-memory data from its serialized bytes. See [Data Serialization](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/07-data-serialization.md).
- **Discriminant**: The expression b² − 4ac of a quadratic equation; its sign says whether the equation has two, one or no real solutions. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **DMA (direct memory access)**: Transfer of data between a device and memory without the CPU handling each byte. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Domain and range**: The domain of a function is the set of its allowed inputs; the range is the set of outputs it actually produces. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **Don't-care condition**: An input combination whose output does not matter, which minimisation may treat as 0 or 1. See [Logic Simplification](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/03-logic-simplification.md).
- **DRAM and SRAM**: DRAM stores a bit as charge on a capacitor and needs refresh; SRAM holds a bit in a latch and is faster but larger. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Driver**: Operating-system software that knows how to control a particular device. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).

## E

- **Embedded computer**: A computer built into a larger product to control it, usually with a dedicated purpose. See [Types of Computers](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/02-types-of-computers.md).
- **Equivalence relation**: A relation that is reflexive, symmetric and transitive. It splits its set into equivalence classes. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Euclid's algorithm**: A method for finding the greatest common divisor by replacing the pair (a, b) with (b, a mod b) until the second number is 0. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).
- **Euler's totient**: φ(n), the number of integers from 1 to n that have no common factor with n other than 1. See [The Pigeonhole Principle and Inclusion-Exclusion](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/04-pigeonhole-and-inclusion-exclusion.md).
- **Exascale**: Computing at $10^{18}$ floating-point operations per second. See [Types of Computers](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/02-types-of-computers.md).
- **Exception (fault)**: An event raised by the instruction being executed, such as division by zero or a protection violation, that transfers control to a handler in the kernel. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Exponent (floating point)**: The field that scales the significand by a power of two. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Exponent (power)**: The number of times a base is multiplied by itself, as in 2¹⁰. Zero, negative and fractional exponents extend the idea. See [Exponents and Logarithms](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/02-exponents-and-logarithms.md).
- **Extraneous solution**: A value that turns up while solving an equation, often after squaring both sides, but does not satisfy the original equation. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).

## F

- **Factorial**: n! = n × (n − 1) × … × 1, the number of ways to arrange n distinct objects. By convention 0! = 1. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Fetch-decode-execute cycle**: The loop a processor repeats: fetch the instruction at the program counter, decode its fields, then execute it. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Fibonacci numbers**: The sequence 0, 1, 1, 2, 3, 5, 8, … in which each term is the sum of the two before it. See [Mathematical Induction and Recurrence Relations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/03-induction-and-recurrence-relations.md).
- **Firmware**: Software stored permanently in a device's own non-volatile memory and closely tied to that device. See [What Is a Computer?](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/01-what-is-a-computer.md).
- **Fixed-point**: A representation that stores a number as an integer with an agreed, fixed position of the radix point. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Flag (status flag)**: A one-bit processor register that records a property of the last result, for example the zero flag, which is set when an arithmetic result was zero. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Flash memory**: Non-volatile memory erased in blocks; used for firmware, SSDs and phones. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Floating-point**: A representation of numbers as a sign, an exponent and a fraction, like scientific notation in base 2. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Floor and ceiling**: The functions that round a number down (floor) or up (ceiling) to a whole number. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).
- **Fraction (rational number)**: A quotient of two integers with a non-zero denominator, such as 3/4. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).
- **Fraction (significand field)**: The field that holds the digits after the leading 1 of a floating-point number's significand. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Full adder and half adder**: Circuits that add bits: a half adder adds two bits; a full adder also accepts an incoming carry. See [Binary Arithmetic](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/03-binary-arithmetic.md).
- **Function (mathematical)**: A rule that assigns to every element of one set, the domain, exactly one element of another set, the codomain. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **Functional completeness (universal gate)**: A set of gates from which every Boolean function can be built; NAND alone and NOR alone are complete. See [Logic Gates and Truth Tables](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/01-logic-gates-and-truth-tables.md).

## G

- **Geometric sequence**: A sequence in which each term is the previous one times a constant ratio. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **GPU (graphics processing unit)**: A processor with thousands of simple cores that runs the same operation on many data elements at once. See [The CPU and the GPU](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/01-cpu-and-gpu.md).
- **Grapheme cluster**: What a reader perceives as one character, which may be several code points. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).
- **Gray code**: A binary code in which consecutive values differ in exactly one bit. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Greatest common divisor (GCD)**: The largest integer that divides two given integers. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).

## H

- **Hamming code**: A family of codes that adds parity bits so that a single flipped bit can be located and corrected. See [Error Detection and Correction](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/02-error-detection-and-correction.md).
- **Hamming distance**: The number of positions in which two equal-length bit strings differ. See [Error Detection and Correction](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/02-error-detection-and-correction.md).
- **Hardware**: The physical equipment of a computer: processor, memory, storage, boards and devices. See [What Is a Computer?](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/01-what-is-a-computer.md).
- **Harvard architecture**: A design with separate memories for instructions and for data. See [What Is a Computer?](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/01-what-is-a-computer.md).
- **Hash collision**: Two different inputs that have the same hash value. The pigeonhole principle makes collisions unavoidable. See [The Pigeonhole Principle and Inclusion-Exclusion](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/04-pigeonhole-and-inclusion-exclusion.md).
- **Hexadecimal**: Base 16, written with the digits 0 to 9 and A to F; each digit stands for exactly 4 bits. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Hidden bit**: The leading 1 of a normal floating-point significand, which is implied and not stored. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).

## I

- **IEEE 754**: The standard that defines floating-point formats, rounding and special values. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Immediate (operand)**: A constant written inside the instruction itself, such as the 5 in `LOADI R1, 5`. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Inclusion-exclusion principle**: A formula for the size of a union: add the sizes of the sets, subtract the pairwise intersections, add the triple intersections, and so on. See [The Pigeonhole Principle and Inclusion-Exclusion](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/04-pigeonhole-and-inclusion-exclusion.md).
- **Inequality**: A statement that one expression is less than or greater than another. Multiplying both sides by a negative number reverses it. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **Injective function**: A one-to-one function: different inputs always give different outputs. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Instruction set architecture (ISA)**: The contract between software and a processor: its instructions, registers, encoding and memory model. x86-64, Arm and RISC-V are ISAs. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Interrupt**: A signal from a device or the timer that makes the CPU pause its work, save its state and run a handler. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md); the device side is described in [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Interrupt handler**: The kernel code that runs when an interrupt, fault or system call occurs and that ends by returning to the interrupted program. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Interrupt storm**: Interrupts arriving so fast that the processor does nothing but handle them and programs make no progress. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Inverse function**: A function that undoes another, so that f⁻¹(f(x)) = x. It exists only when different inputs give different outputs. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).

## K

- **Karnaugh map**: A truth table arranged on a grid with Gray-code axes so that groups of adjacent 1s give simplified product terms. See [Logic Simplification](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/03-logic-simplification.md).
- **Kernel (kernel mode)**: The core of the operating system, which runs in the processor's privileged mode with full access to the hardware. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Kibibyte (KiB), mebibyte, gibibyte**: Binary size units of 2 to the power 10, 20 and 30 bytes; kB, MB and GB mean powers of 1000. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).

## L

- **Latency**: The time a message takes to travel from one place to another. See [Client-Server and Remote Computing](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/03-client-server-and-remote-computing.md).
- **Little-endian**: Byte order that stores the least significant byte at the lowest address. See [Integers, Floating-Point Numbers and Endianness in Memory](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/05-integers-floats-and-endianness-in-memory.md).
- **Load/store architecture**: An instruction set in which only load and store instructions access memory and all others work on registers. Arm and RISC-V are examples. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Locality of reference**: The tendency of programs to reuse recent data (temporal) and to touch nearby data (spatial). See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Logarithm**: The inverse of exponentiation: log_b x = y means b^y = x. In base 2 it counts bits and halvings. See [Exponents and Logarithms](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/02-exponents-and-logarithms.md).
- **Logic gate**: A circuit that computes a Boolean function of one or more binary inputs. See [Logic Gates and Truth Tables](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/01-logic-gates-and-truth-tables.md).
- **Logical CPU and hardware thread**: One of the instruction streams a core can run; the operating system counts each as a CPU. See [The CPU and the GPU](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/01-cpu-and-gpu.md).
- **Loopback address**: An address that refers to the local machine itself; `127.0.0.1` in IPv4. See [Client-Server and Remote Computing](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/03-client-server-and-remote-computing.md).
- **Lossless and lossy compression**: Lossless compression is exactly reversible; lossy compression discards information to be smaller. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).

## M

- **MAC address**: A 48-bit identifier of a network interface on a local network. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Machine code**: The binary instructions that a processor executes. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Machine epsilon**: The gap between 1.0 and the next larger representable floating-point number. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Mathematical induction**: A proof technique: prove a base case and prove that each case implies the next, so that the statement holds for every whole number from the base case on. See [Mathematical Induction and Recurrence Relations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/03-induction-and-recurrence-relations.md).
- **Memoization**: Remembering the results of a pure function so that repeated calls with the same arguments are answered from memory. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **Memory (RAM)**: Fast, volatile working storage that the processor accesses directly by address. See [What Is a Computer?](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/01-what-is-a-computer.md).
- **Memory hierarchy**: The layering of registers, caches, main memory and storage from small and fast to large and slow. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Memory-mapped I/O**: Controlling a device by reading and writing registers that appear at memory addresses. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Microcontroller**: A single-chip computer combining a small processor, memory and peripherals, used in embedded systems. See [Types of Computers](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/02-types-of-computers.md).
- **Minterm and maxterm**: A minterm is a product that is 1 for exactly one input row; a maxterm is a sum that is 0 for exactly one row. See [Boolean Algebra and De Morgan's Laws](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/02-boolean-algebra-and-de-morgans-laws.md).
- **Mnemonic**: The short name of an instruction in assembly language, such as `ADD`. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Mojibake**: Garbled text that results from decoding bytes with a different encoding from the one used to write them. See [Character Encoding and ASCII](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/03-character-encoding-and-ascii.md).
- **Motherboard**: The main circuit board that connects and powers a computer's components. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Multiset**: A collection in which an element can occur more than once. Python's `collections.Counter` is one. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).

## N

- **NaN (not a number)**: The floating-point value produced by invalid operations; every comparison with it is false. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Network byte order**: Big-endian order, specified for multi-byte fields in Internet protocols. See [Integers, Floating-Point Numbers and Endianness in Memory](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/05-integers-floats-and-endianness-in-memory.md).
- **Nibble**: Four bits; one hexadecimal digit. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **NIC (network interface card)**: The hardware that connects a computer to a network. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Normalisation (Unicode)**: Converting equivalent code-point sequences to one canonical form, such as NFC. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).
- **Number and numeral**: A number is an abstract quantity; a numeral is a written representation of it, such as `13`, `XIII` or `1101`. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Nyquist-Shannon sampling theorem**: A signal limited to frequencies below f can be reconstructed from samples taken at more than 2f. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).

## O

- **Octal**: Base 8; each digit stands for exactly 3 bits. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Octet**: Exactly 8 bits; the term Internet standards use for a byte. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).
- **Offset binary (excess-K)**: A representation that stores value plus a constant K as an unsigned number. See [Signed Numbers and Two's Complement](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/04-signed-numbers-and-twos-complement.md).
- **Ones' complement**: A signed representation in which a number is negated by inverting every bit. It has two zeros. See [Signed Numbers and Two's Complement](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/04-signed-numbers-and-twos-complement.md).
- **Opcode**: The field of a machine instruction that says which operation to perform. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Operand**: A value an instruction works on: a register, a constant or a memory address. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Overflow**: A result outside the representable range. For unsigned numbers it shows as a carry out of the top bit; for signed numbers it is detected by the sign rule. See [Signed Numbers and Two's Complement](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/04-signed-numbers-and-twos-complement.md).

## P

- **Padding**: Unused bytes a compiler inserts so that fields are aligned. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).
- **Parity bit**: An extra bit chosen to make the number of 1 bits even (or odd); detects any odd number of flipped bits. See [Error Detection and Correction](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/02-error-detection-and-correction.md).
- **Partial order**: A relation that is reflexive, antisymmetric and transitive, such as divides or is a subset of. Some pairs may be incomparable. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Pascal's triangle**: A triangle of binomial coefficients in which each entry is the sum of the two entries above it. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **PCI Express (PCIe)**: A point-to-point serial interconnect made of lanes, used for graphics cards, SSDs and other devices. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Percentage point**: The arithmetic difference between two percentages. A rate rising from 4% to 5% has risen by one percentage point, or 25% in relative terms. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).
- **Peripheral**: A device attached to a computer for input, output, storage or communication. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Permutation**: An ordering of distinct objects. There are n!/(n − k)! ordered choices of k objects from n. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Pigeonhole principle**: If more than m objects are placed in m boxes, some box holds at least two. In general some box holds at least ⌈n/m⌉. See [The Pigeonhole Principle and Inclusion-Exclusion](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/04-pigeonhole-and-inclusion-exclusion.md).
- **Pixel**: One element of a raster image, usually stored as red, green and blue intensities. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).
- **Pointer**: A variable whose value is a memory address. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).
- **Polling**: Repeatedly checking a device's status instead of waiting for it to signal. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Positional notation**: A way of writing numbers in which a digit's position determines its weight. See [Positional Number Systems](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/01-positional-number-systems.md).
- **Power set**: The set of all subsets of a set. A set with n elements has 2ⁿ subsets. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Power supply unit (PSU)**: The component that converts mains AC to regulated low-voltage DC. See [Motherboard, Power Supply, Network Interface and Peripherals](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/03-motherboard-power-nic-and-peripherals.md).
- **Preemptive multitasking**: Running many programs on one processor by using a timer interrupt to take the CPU from each in turn. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Preimage**: For an output y of a function, the set of inputs that map to y. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Prime implicant**: A product term that implies the function and cannot be shrunk by removing a variable. See [Logic Simplification](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/03-logic-simplification.md).
- **Privileged instruction**: An instruction that only kernel mode may execute, such as halting the processor or talking to a device. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Program counter (PC)**: The register that holds the address of the next instruction to fetch. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Protocol**: An agreed set of message formats and rules that lets a client and a server cooperate. See [Client-Server and Remote Computing](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/03-client-server-and-remote-computing.md).
- **Pure function**: A function whose result depends only on its arguments and that changes nothing outside itself. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).

## Q

- **Quine-McCluskey algorithm**: A systematic procedure that merges minterms into prime implicants and then selects a minimal cover. See [Logic Simplification](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/03-logic-simplification.md).
- **Quotient and remainder**: The result of dividing integer a by b as a = b × q + r. Languages differ in the sign of r when a or b is negative. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).

## R

- **Ratio**: A comparison of two quantities, written a:b, that is unchanged when both are multiplied by the same factor. See [Arithmetic, Fractions, Percentages and Ratios](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/01-arithmetic-fractions-percentages-and-ratios.md).
- **Recurrence relation**: A rule that defines each term of a sequence from earlier terms, together with initial conditions. See [Mathematical Induction and Recurrence Relations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/03-induction-and-recurrence-relations.md).
- **Redundancy**: Extra information added to data so that damage can be detected or repaired. See [Error Detection and Correction](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/02-error-detection-and-correction.md).
- **Register**: A small, fast storage location inside the CPU that the ALU can use directly. See [The Fetch-Decode-Execute Cycle](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/01-the-fetch-decode-execute-cycle.md).
- **Relation**: A set of ordered pairs. A relation on a set A is a subset of A × A. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **ROM (read-only memory)**: Non-volatile memory, today usually a flash chip holding firmware. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Round to nearest, ties to even**: The default IEEE 754 rounding rule: pick the nearest representable value, and on a tie the one with an even last bit. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Rule of sum and rule of product**: If two tasks cannot both happen and can be done in m and n ways, there are m + n ways to do one of them. If two steps follow one another, there are m × n ways to do both. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).

## S

- **Sample rate**: The number of measurements of a signal taken per second. See [Image, Audio and Video Encoding](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/06-image-audio-and-video-encoding.md).
- **Saturation**: Clamping a result to the largest (or smallest) representable value instead of wrapping around. See [Binary Arithmetic](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/03-binary-arithmetic.md).
- **Schema**: A declared description of the structure of data. See [Data Serialization](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/07-data-serialization.md).
- **SECDED**: Single-error-correcting, double-error-detecting code, as used in ECC memory. See [Error Detection and Correction](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/02-error-detection-and-correction.md).
- **Sequence**: An ordered list of numbers a₁, a₂, a₃, …, given by a formula or by a recurrence. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Serialization**: Converting in-memory data into a sequence of bytes for storage or transmission. See [Data Serialization](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/07-data-serialization.md).
- **Series**: The sum of the terms of a sequence, written with the sigma symbol. See [Sequences, Permutations and Combinations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/02-sequences-permutations-and-combinations.md).
- **Server**: A program (or the machine running it) that waits for requests and provides a service. See [Client-Server and Remote Computing](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/03-client-server-and-remote-computing.md).
- **Set**: A collection of distinct objects in which order and repetition do not matter. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Side effect**: A change a function makes to something outside itself, such as a variable, a file or the screen. See [Algebra, Equations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/03-algebra-equations-and-functions.md).
- **Sign extension**: Widening a signed value by copying its sign bit into the new high bits. See [Signed Numbers and Two's Complement](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/04-signed-numbers-and-twos-complement.md).
- **Sign-magnitude**: A signed representation with a sign bit and a magnitude. It has two zeros. See [Signed Numbers and Two's Complement](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/04-signed-numbers-and-twos-complement.md).
- **SIMD and SIMT**: Executing one instruction on many data elements at once, in vector units (SIMD) or groups of GPU threads (SIMT). See [The CPU and the GPU](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/01-cpu-and-gpu.md).
- **Square-and-multiply**: A fast way to compute a power by repeated squaring, multiplying in the squares that match the 1 digits of the exponent. See [Exponents and Logarithms](docs/01-computer-science-foundations/02-mathematics-for-computer-science/01-basic-mathematics/02-exponents-and-logarithms.md).
- **SSD and HDD**: A solid-state drive stores data in flash; a hard disk drive stores it magnetically on spinning platters. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Stateless**: Describes a protocol in which each request carries everything needed to process it, so the server keeps no memory of earlier requests. See [Client-Server and Remote Computing](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/03-client-server-and-remote-computing.md).
- **Stored-program concept**: The design in which instructions and data are both held as bit patterns in the same memory. See [What Is a Computer?](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/01-what-is-a-computer.md).
- **Strong induction**: Induction in which the step may use every earlier case, not only the previous one. See [Mathematical Induction and Recurrence Relations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/03-induction-and-recurrence-relations.md).
- **Structural induction**: Induction over a recursively defined structure, such as a list or a tree. See [Mathematical Induction and Recurrence Relations](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/03-induction-and-recurrence-relations.md).
- **Subnormal**: A floating-point number smaller than the smallest normal number, stored without a hidden bit, giving gradual underflow. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Sum of products and product of sums**: Two standard forms of a Boolean expression: an OR of AND terms, or an AND of OR terms. See [Boolean Algebra and De Morgan's Laws](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/02-boolean-algebra-and-de-morgans-laws.md).
- **Supercomputer**: A system built to run one very large job across a very large number of processors in parallel. See [Types of Computers](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/02-types-of-computers.md).
- **Surjective function**: An onto function: every element of the codomain is an output. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Surrogate pair**: Two UTF-16 code units that together encode a code point above U+FFFF. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).
- **System call**: A request from a program to the kernel, made with a special instruction that enters the kernel through the vector table. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).

## T

- **Tag-length-value (TLV)**: A format in which each field is a tag, a length and a value, so readers can skip unknown fields. See [Data Serialization](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/07-data-serialization.md).
- **Timer interrupt**: An interrupt raised by a hardware timer at regular intervals, which lets the kernel regain control and switch programs. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Transitive closure**: The smallest transitive relation that contains a given relation. It describes what can be reached by following links. See [Sets, Relations and Functions](docs/01-computer-science-foundations/02-mathematics-for-computer-science/02-discrete-mathematics/01-sets-relations-and-functions.md).
- **Truth table**: A table listing a function's output for every combination of inputs. See [Logic Gates and Truth Tables](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/01-logic-gates-and-truth-tables.md).
- **Two's complement**: The standard signed integer representation, in which the top bit has negative weight and negation is invert-and-add-one. See [Signed Numbers and Two's Complement](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/04-signed-numbers-and-twos-complement.md).

## U

- **Ulp (unit in the last place)**: The gap between a floating-point number and the next representable one. See [Floating-Point Representation and IEEE 754](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/05-floating-point-and-ieee-754.md).
- **Unicode**: The standard that assigns a unique code point to every character of every writing system. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).
- **Unsigned**: Interpreting a bit pattern as a non-negative integer from 0 to $2^n - 1$. See [Signed Numbers and Two's Complement](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/04-signed-numbers-and-twos-complement.md).
- **User mode**: The restricted processor state in which ordinary programs run, with no privileged instructions and no access to kernel memory. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **UTF-16**: A Unicode encoding that uses one or two 16-bit code units per code point. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).
- **UTF-8**: A variable-length Unicode encoding of one to four bytes that is ASCII-compatible. See [Unicode, UTF-8 and UTF-16](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/04-unicode-utf-8-and-utf-16.md).

## V

- **Vector table**: A table in memory holding the address of the handler for each kind of interrupt, fault or system call. See [Interrupts and System Calls](docs/01-computer-science-foundations/01-computer-fundamentals/06-how-computers-execute-instructions/02-interrupts-and-system-calls.md).
- **Von Neumann architecture**: A stored-program design in which instructions and data share one memory. See [What Is a Computer?](docs/01-computer-science-foundations/01-computer-fundamentals/01-introduction-to-computers/01-what-is-a-computer.md).

## W

- **Wear levelling**: Spreading writes evenly across flash cells so that none wears out early. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).
- **Word**: The natural unit of data of a processor, commonly 16, 32 or 64 bits. See [Bits, Bytes, Words and Memory Addresses](docs/01-computer-science-foundations/01-computer-fundamentals/03-data-representation/01-bits-bytes-words-and-addresses.md).
- **Wraparound**: Keeping only the low $n$ bits of a result, so values wrap modulo $2^n$. See [Binary Arithmetic](docs/01-computer-science-foundations/01-computer-fundamentals/02-number-systems/03-binary-arithmetic.md).
- **Write-back and write-through**: Write-through updates memory on every write; write-back updates it only when a modified line is evicted. See [Memory and Storage: RAM, ROM, Cache, SSD and HDD](docs/01-computer-science-foundations/01-computer-fundamentals/05-computer-components/02-memory-and-storage.md).

## X

- **XOR (exclusive or)**: A gate that outputs 1 when exactly one input is 1; addition of two bits without carry. See [Logic Gates and Truth Tables](docs/01-computer-science-foundations/01-computer-fundamentals/04-boolean-logic/01-logic-gates-and-truth-tables.md).
